## 数字を知りたいときはノートを見ない

金額・人数・立替の「正」は `data/rugby/` のデータファイルであり、
ノートの数表は書いた時点のスナップショットにすぎない。
リポジトリのルートで下記を実行すること。

```bash
python3 -m scripts.kaikei check       # 会計の全検証
python3 -m scripts.kaikei settle --all # 立替金（合宿＋年間）
python3 -m scripts.nenkan now         # 今月やること
python3 -m scripts.anzen check        # 安全調査の回収状況
```

環境を作り直したら `pip install -r requirements.txt`。
