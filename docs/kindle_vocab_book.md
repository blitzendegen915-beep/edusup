# Kindle用 英単語帳ジェネレーター の使い方

スプレッドシートで作った単語リスト（CSV）から、**Kindle（KDP）にそのままアップロードできる電子書籍（EPUB）** を自動で作ります。

- コード: `kindle/vocab-book/build.js`（Node.js の標準機能だけ。`npm install` 不要）
- 単語データ: `kindle/vocab-book/words.csv`（サンプル100語入り）
- 本の設定: `kindle/vocab-book/book.json`
- デザイン: `kindle/vocab-book/book.css`
- 表紙: `kindle/vocab-book/cover.jpg`（サンプル。1600×2560px）

## どんな本ができるか（集中が続かない生徒向けの設計）

ショート動画に慣れて、長い単語リストだと集中が続かない生徒向けに、「すぐ次へ進める」「すぐ結果がわかる」ことを最優先にした構成です。

```
もくじ → この本の使い方（30秒）
  ↓
STAGE 1 扉（このステージの10語・目安時間）
  ↓
単語カード ×10（1ページ1単語。3秒見たら次へスワイプ）
  ↓
ボス戦 ×10問（選択肢をタップ → 「◎正解！+10XP」/「×ざんねん」ページへジャンプ）
  ↓
CLEAR!! 答え合わせ＋ランク判定（S/A/B/C）
  ↓
STAGE 2 … STAGE 10 → ラスボス戦（全ステージから20問）→ ALL CLEAR → さくいん
```

| 仕掛け | ねらい |
| --- | --- |
| 1ページ1単語・進捗バー（■■■□□□）・「ゲット 3 / 100」 | めくるたびに進んだ感覚が得られる |
| レア度（N / R / SR / SSR） | ガチャ・カード集めの感覚で難しい単語を印象づける |
| ボス戦（タップで正解/不正解ページにジャンプ） | すぐに答えがわかる（Kindleのリンク機能でゲームブックのように動く） |
| XP・ランク判定 | 自分で点数を数えて、もう一度やりたくなる |
| 例文はスマホ・ゲーム・学校の場面 | 「自分のこと」として読める |
| 覚え方・発音のカタカナ（強く読む部分は太字）・＋α | 1ページで覚えるきっかけがそろう |

単語カード1枚の中身:

```
No.063 ｜ STAGE 7 ｜ 3 / 10
■■■□□□□□□□
SR ★★★
awkward
オークワード（「オー」が太字）
［形］気まずい、ぎこちない
┌覚え方──────────────────────┐
│会話が止まったときの「……（気まずっ）」が awkward。│
└─────────────────────────┘
┌例文───────────────────────────────┐
│There was an awkward silence after my joke.（awkward は太字）│
│私のギャグのあと、気まずい沈黙が流れた。                    │
└────────────────────────────────┘
＋α an awkward moment（気まずい瞬間）
```

## 1. まず作ってみる（パソコンで1回だけ準備）

1. [Node.js](https://nodejs.org/ja) の「LTS」版をインストールする（インストーラーの初期設定のままでOK）。
2. このリポジトリをパソコンに置く（GitHubの緑の「Code」→「Download ZIP」で展開するだけでも可）。
3. ターミナル（Windowsは「PowerShell」）を開き、リポジトリのフォルダに移動して実行する。

```
node kindle/vocab-book/build.js
```

成功すると `kindle/vocab-book/dist/` に次のファイルができます。

| ファイル | 使い道 |
| --- | --- |
| `swipe-eitango-100.epub` | **KDPにアップロードする原稿** |
| `cover.jpg` | **KDPにアップロードする表紙** |
| `preview.html` | ダブルクリックでブラウザが開き、全ページを確認できる（選択肢のクリックでジャンプも試せる） |
| `kdp-listing.txt` | KDPの入力欄（タイトル・フリガナ・内容紹介・キーワードなど）に貼る内容のメモ |

画面には「正解の位置（偏りチェック）」も表示されます（例: `STAGE 1: ①2 ②3 ③3 ④2`）。

## 2. 単語を入れ替える（words.csv）

`words.csv` を Googleスプレッドシート または Excel で開いて編集します。1行目は見出しなので消さないでください。

| 列 | 内容 | 必須 | 例 |
| --- | --- | --- | --- |
| stage | ステージ番号（1から順に） | ○ | `1` |
| word | 見出し語 | ○ | `avoid` |
| pos | 品詞（先頭1文字が［動］のように表示される） | ○ | `動詞` / `形容詞` / `名詞` / `副詞` |
| meaning | 意味（クイズの選択肢にもなるので短めに） | ○ | `～を避ける` |
| reading | 発音のカタカナ。**強く読む部分を [ ] で囲むと太字** | | `ア[ヴォ]イド` |
| rarity | レア度 `N` / `R` / `SR` / `SSR`（空欄なら表示しない） | | `SR` |
| hook | 覚え方のヒント（1〜2文） | | `void＝「空っぽ」。…` |
| example | 例文（15語以内がおすすめ）。見出し語は自動で太字。うまくいかないときは太字にしたい部分を `[ ]` で囲む | | `I avoid eye contact …` |
| example_ja | 例文の訳 | | `先生が質問するとき…` |
| plus | ＋α（セットで覚える表現・反意語など） | | `avoid ～ing（～するのを避ける）` |

保存のしかた:

- **Googleスプレッドシート**: ファイル → ダウンロード → カンマ区切り形式（.csv）→ `words.csv` という名前で上書き
- **Excel**: 名前を付けて保存 → ファイルの種類「**CSV UTF-8（コンマ区切り）**」（ただの「CSV」だと文字化けします。その場合はエラーで教えてくれます）

1ステージの単語数は自由です（4個以上。10個前後がおすすめ）。ステージ名は `book.json` の `stages` で付けます。

## 3. テストとしての品質チェック（自動）

ボス戦は「テスト」なので、生成時に次のチェックを自動で行います。問題があるとエラーで止まり、何行目を直せばよいかが表示されます。

| チェック | 内容 |
| --- | --- |
| 正解の一意性 | 意味がまったく同じ単語が2つあるとエラー（日本語→英語の問題で正解が2つになるため） |
| 紛らわしい選択肢 | `book.json` の `quiz.avoidTogether` に書いた組（例: `["deny", "refuse"]`）は、同じ問題の選択肢に並べない |
| 選択肢の偏り | 正解の位置（①〜④）を各ステージで均等に割り振り、同じ番号が3問以上続かないようにする |
| 設問番号のずれ | 選択肢の重複・正解位置のずれがないか最終確認する |
| データの書式 | 必須列の空欄・単語の重複・レア度の書き間違い・文字コード・[ ] の対応 |

- 問題の並びと選択肢は「シード付き乱数」で決まるので、**何度作り直しても同じ問題になります**（単語を変えると並びも変わります）。
- 意味が近い単語（例: prevent「防ぐ」と protect「守る」）を足したときは、`avoidTogether` に組を追加してください。生徒が「どっちも正解では？」と言えそうな組が目安です。

## 4. 本の設定（book.json）

| 項目 | 内容 |
| --- | --- |
| `title` / `subtitle` / `badge` | タイトル・サブタイトル・扉の上の小見出し |
| `author` / `publisher` | 著者名・発行者名（ペンネームや屋号でOK） |
| `publishDate` / `edition` | 発行日（`2026-10-06` の形）・版 |
| `fileName` | 出力するEPUBのファイル名（半角英数字） |
| `identifier` | 本の固有ID。**一度決めたら変えない**（改訂版も同じIDで上書きアップロードする） |
| `stages` | ステージ番号ごとの名前 |
| `quiz.choices` | 選択肢の数（2〜6。標準は4） |
| `quiz.xpPerCorrect` | 1問正解のXP |
| `quiz.finalBossQuestions` | ラスボス戦の問題数（0にするとラスボス戦なし） |
| `quiz.avoidTogether` | 同じ問題の選択肢に並べない単語の組 |
| `howToUse` / `tips` / `allClearMessage` | 「使い方」ページと「ALL CLEAR」ページの文章。`{words}`（総単語数）`{stages}`（ステージ数）`{xp}` `{wordsPerStage}` は自動で数字に置き換わる |
| `kdp` | KDPに入力するフリガナ・ローマ字・内容紹介・キーワード・カテゴリー（`kdp-listing.txt` に書き出される） |

文字の大きさや枠線は `book.css` で変えられます。Kindleの黒背景モードやE Ink端末で崩れないよう、**文字色・背景色は指定しない**でください。

## 5. Kindle Previewer で見え方を確認する

`preview.html` は簡易表示です。出版前に、Amazon公式の無料ソフト **Kindle Previewer 3**（Windows / Mac）で確認してください（「Kindle Previewer」で検索するとAmazonの公式ページが出ます）。

1. Kindle Previewer で `dist/swipe-eitango-100.epub` を開く
2. 左上の端末の種類で「タブレット」「スマートフォン」「Kindle（E Ink）」を切り替えて見る
3. 確認するところ
   - 単語カードが1画面に収まっているか（文字サイズを大きくすると2画面に分かれるのは正常）
   - ボス戦の選択肢をタップすると「正解！」「ざんねん！」のページに飛び、「▶ 次の問題へ」で戻れるか
   - もくじ・さくいんのリンクが飛ぶか

## 6. KDP で出版する

※ 2026年10月時点の一般的な流れです。画面や条件は変わることがあるので、最終的には KDP のヘルプを確認してください。

### 初回だけ

1. [KDP（kdp.amazon.co.jp）](https://kdp.amazon.co.jp/) に Amazon アカウントでサインイン
2. アカウント情報で「著者/出版者情報」「支払い受け取り（銀行口座）」「税に関する情報」を登録
   - 税に関する情報は画面の質問に答える形式です。日本在住なら日米租税条約の適用を選ぶことで、米国での源泉徴収が通常 0% になります。

### 本を登録する（「＋作成」→「Kindle 電子書籍」）

`dist/kdp-listing.txt` を見ながら入力すると楽です。

1. **詳細情報**: 言語「日本語」、タイトル（フリガナ・ローマ字）、サブタイトル、著者、内容紹介、キーワード（最大7つ）、カテゴリー
2. **コンテンツ**:
   - 原稿 → `swipe-eitango-100.epub` をアップロード
   - 表紙 → 「アップロード済みの表紙を使用」で `cover.jpg`
   - **AI生成コンテンツ** → 下の注意を読んで正しく申告する
   - 「プレビューアーを起動」で最終確認
3. **価格設定**:
   - ロイヤリティ 70% を選ぶには、Amazon.co.jp では販売価格を 250〜1,250 円の範囲にします（70% の場合はファイルサイズに応じた配信コストが引かれます。この本は約0.6MBなのでごくわずか）
   - **KDPセレクト**（Kindle Unlimited の読み放題対象になる）は任意。登録中の90日間は、この本の電子版を他の場所で配布できません（下の注意を参照）
4. 「Kindle本を出版」→ 審査（最大72時間程度）→ 販売開始

### 改訂版を出すとき

`words.csv` を直して作り直し、KDP の本棚から同じ本の「電子書籍のコンテンツを編集」で EPUB を差し替えます（`identifier` は変えない）。

## 7. 2巻目・別シリーズを作る

`kindle/vocab-book` フォルダの `book.json` `words.csv` `cover.jpg`（必要なら `book.css`）を別フォルダにコピーし、フォルダを指定して実行します。

```
node kindle/vocab-book/build.js 別フォルダのパス
```

`book.json` の `title` `fileName` と、**`identifier`（新しい本なので新しいIDにする）** を変えてください。`identifier` を消して実行すると、タイトルから自動で新しいIDを作ります（画面に表示されるIDを `book.json` に書いておくと安全です）。

## 注意点（必ず読んでください）

- **販売する単語データは、このリポジトリに置かないでください。** このリポジトリは公開設定（教材ストアのため）なので、`words.csv` に入れた内容は誰でも読めます。本の中身がネット上で無料で読める状態になり、KDPセレクトの独占配信の条件にも反するおそれがあります。販売用の本は、上の「7.」のやり方でリポジトリの外（自分のパソコンや非公開リポジトリ）のフォルダで作ってください。いま入っている100語はサンプルです。
- **AI生成コンテンツの申告**: 同梱のサンプル単語データ（覚え方・例文・訳）と表紙は AI（Claude）が作成したものです。そのまま、または手直しして出版する場合は、KDP の「AI生成コンテンツ」の質問に「はい」と答え、該当する項目（テキスト・画像）を申告してください。自分で一から書き直したものは申告不要です（KDPでは、AIを推敲などの補助に使っただけなら申告は不要とされています）。
- **出版前に内容を必ず人の目で確認**してください。意味・例文・訳・カタカナ発音（強く読む位置）・覚え方は確認済みのつもりですが、教材として出す前に英語の先生の目で最終チェックをお願いします。覚え方の語源の説明のうち、確かでないものは「〜という説も」「音が似てる」と書き分けています。
- **タイトル・内容紹介に「ドパガキ」などの俗語は入れない**ほうが無難です。保護者や先生が買う場面で印象が悪く、レビューにも影響します。「スキマ時間」「ゲーム感覚」「1ページ1単語」「集中が続かない人でも」などの言い方がおすすめです。
- 例文に実在の人物・企業名・商品名・個人情報は入れないでください（サンプルも架空の場面だけです）。
- 「ゲット 3 / 100」などの数字は自動で計算されます。単語を増やしたり減らしたりしても直す必要はありません。

## GitHub での自動チェック

`kindle/` 配下を変更して push すると、GitHub Actions（「Check Kindle vocab book」）が EPUB を作り、KDP が使うのと同じ形式チェック（EPUBCheck）にかけます。Actions タブに赤い × が出たら、ログに表示されたエラーの行を直してください。公開リポジトリなので、作った EPUB はダウンロードできる形では保存しません。

## 400語版（スワイプ英単語400）の作り方メモ

100語のサンプルに、市販単語集の見出し語リストを「選ぶときの目安」にして300語を足し、40ステージ・400語にした版です。**400語版のデータ（words.csv・EPUB）はこのリポジトリに入れていません**（公開リポジトリのため）。作り方だけを残します。

- 構成: 1〜10（サンプル100語）＋ 11〜40（動詞100・名詞100・形容詞80・つなぎことば10・ラスボス級10）
- 意味・覚え方・例文・訳・カタカナ発音は、すべて自分で書き下ろす（市販単語集の訳語や例文は写さない）
- レア度は元リストの難易度（数字が大きいほど難しい）から自動で決めた（〜10: N / 〜25: R / 〜40: SR / それ以上: SSR）
- `book.json` は `finalBossQuestions: 40`（ラスボス戦を全ステージから1問ずつ）、`identifier` は新しいUUID、`quiz.avoidTogether` は意味が近い単語の組を60組ほどに増やす
- ステージ数が増えるとページ数も増える（400語版は1,849ページ・約1.5MB）。KDPの70%ロイヤリティでもファイル配信コストはごくわずか
- 実行は別フォルダを指定する: `node kindle/vocab-book/build.js <400語版のフォルダ>`

注意: 市販単語集の名前（書名）は、本のタイトル・紹介文・キーワードに入れないでください。「◯◯準拠」「◯◯対応」とも書かないでください（商標・出版社とのトラブルのもとです）。
