## 1. これは何か

駒澤大学高等学校ラグビー部（部員43名）の運営を自動化するリポジトリ。
顧問は **占部涼也**（英語科）と **畠山和真**（体育科・監督）の2名。
占部先生が会計・事務を担当している。

もともとは書類を1枚ずつ手で作っていた。2026年の夏合宿で、
名簿の重複1件が全費用の再計算を引き起こし、コーチの日程変更のたびに
人数表を作り直す事態になった。**同じ数字を4回打ち直していたのが原因**。

そこで「データは1か所、書類は生成、異常は機械が検出」に作り替えた。
**この方針を崩さないこと。** 数字をチャット上で電卓的に計算して答えるのは禁止。

## 2. 3つのシステム

### kaikei — 会計

```bash
python3 -m scripts.kaikei check       # 全検証。まずこれ
python3 -m scripts.kaikei balance     # 収支
python3 -m scripts.kaikei settle --all # 立替金（合宿＋年間を合算）
python3 -m scripts.kaikei headcount   # 日別・食事別の人数
python3 -m scripts.kaikei ledger      # 年間経費を会計分類別に
python3 -m scripts.kaikei report      # xlsx一式を output/ に生成
python3 -m scripts.kaikei add ...     # 領収書を1件追加
python3 -m scripts.kaikei claim y001  # 事務室から受領したら記録
```

### nenkan — 年間業務

```bash
python3 -m scripts.nenkan now         # 今月やること・未完了のまま過ぎた業務
python3 -m scripts.nenkan done <id>   # 終わったら記録
```

### anzen — 安全管理（合宿・遠征帯同用）

```bash
python3 -m scripts.anzen check        # アンケート回収状況・未回答者
python3 -m scripts.anzen generate     # 緊急時対応シート等3種を生成
```

テスト: `python3 tests/test_kaikei.py` / `test_nenkan.py` / `test_anzen.py`
（合計320件超。**変更したら必ず全部通すこと**）

環境を作り直したら `pip install -r requirements.txt`。

## 3. データの場所（人が触ってよいのはここだけ）

```
data/rugby/
  roster-2026.csv             部員名簿。参加可否・合流日・合流食
  camp-2026-summer.yml        合宿の日程・単価・大人の帯同・徴収額
  expenses-2026-summer.csv    合宿の支出（領収書番号 rNNN）
  ledger-2026.csv             合宿以外の年間支出（領収書番号 yNNN）
  annual-tasks.yml            年間業務16件
  task-log-2026.csv           年間業務の完了記録
  prior-year-misc-2025.csv    昨年の雑費36件（比較の基準）
  survey-sample.csv           安全調査のサンプル（架空データのみ）
```

`output/` 配下は**すべて生成物**。手で編集しないこと。
データを直して再生成する。手で直すとデータと生成物が食い違う。

`docs/rugby/基礎データ.md` は連絡先・口座・単価の一元データ。
`docs/rugby/2026夏合宿_会計記録.md` は一次資料（請求書）・前例・経緯の記録。
**数値の正はあくまで `data/rugby/`** で、mdの数表はスナップショット。

## 4. 部の会計ルール（間違えると揉める）

### 会計分類

| 分類 | 内容 | 財源 |
|---|---|---|
| A | 大会参加費・協会登録費 | 校友会予算。**事務室へ請求して受け取る** |
| B | メディカル・補食・コーチ謝礼・対戦校への手土産 | 父母会予算 |
| C | 合宿費・ウェア代 | 各家庭から都度徴収 |

### 精算と請求は別物

- **精算 `settled`** … 立て替えた先生に部がお金を返したか（部 → 先生）
- **請求 `claimed`** … 校友会予算を事務室から受け取ったか（事務室 → 部）

**分類Aはこの両方が起きて初めて完結する。** 先生に返金しても、
事務室に請求しなければ部がその金額を失う。`claimed=yes` にするのは
事務室から実際に入金があったときだけ。

### 口座を間違えないこと

- 三菱UFJ 世田谷支店 普通0887504 … 各家庭からの振込・業者への支払い
- 三井住友 桜新町支店 普通6677190 … 校友会・父母会予算の入金

## 8. 絶対に守ること

1. **金額・人数をチャット上で計算して答えない。** コマンドを実行し、
   その出力を示す。この部は過去に曜日の誤記とサイズの誤記を配布して
   事故を起こしている。
2. **生成物を手で編集しない。** データを直して再生成する。
3. **データを直したら `check` を通す。** 警告は潰すか、潰せない理由を
   記録に残す。
4. **`output/anzen/` は絶対にコミットしない。** 未成年の医療情報が入る。
   `.gitignore` 済み。合宿後は紙も回収して廃棄する。
5. **要配慮個人情報を公開サイト・共有ドライブに置かない。**
6. 生徒個人のデータをサンプルに使わない。架空データを使う。
