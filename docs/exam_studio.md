# 定期考査スタジオ 使い方ガイド

教材の文をクリックして、**聞きたいところを、聞きたい形式で**作問できるツールです。
ブラウザで操作しますが、インターネットには接続しません（このPCの中だけで動きます）。

---

## 1. はじめに

### いちばん簡単：Windows版（Pythonのインストール不要）

1. GitHub のリポジトリの **Releases** から最新の `ExamStudio-windows.zip` をダウンロード
2. ZIP を右クリック →「**すべて展開**」（ZIPのまま開かない）
3. 展開したフォルダの **`ExamStudio.exe` をダブルクリック**

初回に「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」を押します
（署名のない自作ソフトに出る表示です）。他の先生にはこのフォルダごと渡せば使えます。

### Pythonが入っているPCなら

| PC | 操作 |
|---|---|
| Windows | `start_exam_studio.bat` をダブルクリック |
| Mac | `start_exam_studio.command` をダブルクリック |
| 手動 | このフォルダで `python -m exam_app.ui` |

（Python は https://www.python.org/ から。インストール画面の「Add python.exe to PATH」に必ずチェック）

どちらの方法でも、黒い画面が開いたあとブラウザで「定期考査スタジオ」が開きます。

> 黒い画面は**閉じないでください**（閉じるとツールが止まります）。
> 使い終わったら黒い画面を閉じれば終了です。入力内容は自動で保存されています。

## 2. 作り方の流れ

### ホーム画面（試験の一覧）

- 上の **「試験」「テンプレート」** タブで切り替えます
- **カテゴリー**（定期考査・英単語テスト・小テスト・その他）で試験を絞り込めます。
  「編集」を押すと、カテゴリーの追加・名前の変更・並べ替えができます（名前を変えると、その試験とテンプレートにも反映）
- 右上の検索欄で試験名から探せます。試験カードのボタンで **カテゴリーの変更・複製・削除**
- **新しい試験** → カテゴリーを選ぶと、そのカテゴリーのテンプレートと試験名のひな型が自動で入ります

### テンプレート（試験の「型」）

大問の構成・配点・指示文・語群・採点基準と、番号の振り方・見出し・表紙などの体裁をまとめたものです
（問題そのものは含みません）。実物の試験をもとにした標準テンプレートが入っています。

| 標準テンプレート | 内容 |
|---|---|
| 長文総合型（100点） | 大問1 長文（空所・和訳・指示語・並べ替え・内容一致）→ 大問2 対話文 → 大問3 文法 → 大問4 英作文 |
| 英語コミュニケーションⅠ型（90点） | リスニング → 語義 → 空所補充 → 並べ替え（番号で答える） → アクセント → 表 → 内容一致 → 英作文・Retelling。表紙・通し番号 |
| 英語コミュニケーションⅡ型（80点） | 空所補充 → 読解 → 語句選択 → 語句挿入 → 英文解釈 → 並び替え → 長文 → 語群選択 |
| 英語演習型（94点） | 英文識別 → 文型 → 空所選択 → 誤文訂正 → 並べ替え（不要語あり） → 空所補充 → 同意文 → 書き換え → 英作文。解答用紙に「瞬英」欄 |
| 英単語テスト型（100問） | Listening → 英英定義 → 英→日 → 日→英 → 例文4択 → 例文の綴り。【1】見出し・通し番号・各1点 |
| 単語小テスト（20問） | 英→日の4択10問 ＋ 例文の綴り10問 |

- **自分用に作る**: 「テンプレート」タブ →「複製して編集」／「新しいテンプレート」
- **今の試験を型として残す**: 試験の設定 →「テンプレートとして保存」（次回から新規作成で選べます）
- **途中で型を変える**: 試験の設定 →「テンプレートを適用」

### 大問 ＝ 素材（本文）＋ 設問（問1・問2…）

大問は「1つの形式」ではなく、**1つの素材に、いろいろな設問を並べたもの**として作ります。

```
大問1  次の英文を読んで、後の問いに答えなさい。   ← 大問の指示文
       ┌ 本文（枠つきで問題用紙に載る） ┐
       問1 空所補充（3問）  問2 下線部和訳  問3 指示語  問4 並べ替え  問5 内容一致
大問2  対話文 ＋ 問1 空所選択・問2 英問英答
大問3  文法（問1 選択・問2 並べ替え・問3 語形変化）
大問4  英作文だけ
```

- 試験の設定で「大問を追加」→ **長文読解・対話文・リスニング・文法・英作文** のひな型、または形式を1つ選んで追加
- 大問カードの「**この大問に設問を追加**」で、同じ本文に別の形式の設問を足せます
- 「↑ 前の大問の設問にする」「ここから別の大問にする」で、大問をまとめたり分けたりできます
- 標準テンプレート「**長文総合型**」は上の形そのものです（英コミュⅠ型の大問1＝リスニング No.1〜3 も1つの大問）

### いちばん簡単な作り方：AIに注文する

形式を選ぶ必要はありません。**作りたい問題を普通の文章で書くだけ**です。

1. 試験の設定で「**大問を追加**」→「作りたい問題」に書く
   （例: `内容一致を2問、同意語選択を1問。第2段落の筆者の主張に関する問題を中心に。`）
2. 大問をつくる で素材を入れ、「この素材を本文にする」
3. 「**AIに注文して作る**」→「Claudeで作る」（または ChatGPT）
   → 内容一致・同意語選択など **種類ごとに 問1・問2… へ自動で振り分け**られます
- APIキーがなくても「依頼文をコピー」→ Claude / ChatGPT の画面に貼り付け →「結果を貼り付けて取り込む」で同じことができます
- 根拠（出典）のない問題は自動で捨てます。作った問題は必ず教員が確認してください

画面左の 1〜4 を順に進めます。**大問を1つずつ、その大問の素材を入れて作る**流れです。

### ① 試験の設定

- **試験の基本情報**: 試験名・カテゴリー・満点・実施日（表紙か1行目に表示）
- **用紙の体裁**（「変更する」で開く）
  - 問題番号: **大問ごと (1)(2)…** か **通し番号 1, 2, 3…**（通し番号では並べ替えの答える箇所ごとに番号が振られます）
  - 大問の見出し: **「１　指示文（9点）」** か **「【1】指示文（各1点）」**
  - 解答用紙の記入欄（例: 組,番,氏名,瞬英,合計）・問題用紙の最後の一言
  - **表紙**（学年・科目・試験名・実施日・受験上の注意）
- **大問**: 形式・問数・配点・指示文。「詳細設定」で **選択肢の記号（1. / ア / ① / a.）・語群・採点基準・解答用紙で1行に並べる問題数**
- 画面右上の **配点メーター** が緑になれば、配点合計と満点が一致しています（ずれていれば「満点を配点合計に合わせる」）

### ② 大問をつくる ―― このツールの中心

上のタブで大問を、その下の **問1・問2…** で設問を選ぶと、**左に大問の素材（設問で共通）、右にその設問の問題**が並びます。
長文の大問は、素材を入れて **「この素材を本文にする」**（または見出しの「本文を入れる」）を押すと、問題用紙の大問見出しのすぐ下に本文が枠つきで載ります。
本文には `__語句__` で下線、(A) ① などの記号を書けます（本文の語そのものは書き換えない）。

1. **素材を入れる**：その大問で使う本文・例文の Word ファイル（.docx）をドロップするか、
   「貼り付けて追加」で英文を貼り付けます（素材の名前は出典として問題に記録されます）。
   PDF は読めないので本文をコピーして貼り付けてください。別の大問の素材を使い回すこともできます
2. **文をクリック → 形式を選ぶ**：素材の文をクリック（範囲はドラッグ）すると形式メニューが出ます。
   その大問の形式がおすすめとして強調表示されます
3. **語をクリックして仕上げる**：「クイック作問」で下の操作をすると、問題がいま開いている大問に入ります

| 形式 | 操作 | 自動でやってくれること |
|---|---|---|
| 空所補充 | 空所にしたい語をクリック（2回目で頭文字ヒント付き） | 語数どおりの解答枠（must have left → 3枠） |
| 並び替え | 語をクリックで（ ）の外に固定、語の間の「＋」でチャンク化 | シャッフル、文頭語の小文字化、別解の警告。**答え方（語句／番号／記号）・不要語・解答位置の行（ `I will (　) ( 34 ) …` ）** |
| 内容一致 | 設問文と選択肢（本文と一致する文・食い違う文）を書き、●で正解を選ぶ | 選択肢の重複チェック・記号は大問の設定に合わせる |
| 4択 | 空所にする語をクリック、誤答を3つ入力 | 選択肢の記号は大問の設定に合わせる、重複チェック |
| 誤文訂正 | 下線を引く語句を選び（ア・イ・ウ）、誤りにする箇所と誤りの形を入力 | 解答「ウ / are」・解答枠「誤りの箇所／正しい形」。**変えた箇所は「改変箇所」として記録** |
| 語形変化 | 語を1つクリック、原形を入力 | （ make ）の形で出題、原形と答えが同じなら警告 |
| 下線部・和訳 | 範囲の**最初と最後の語**をクリック | 下線付きで出題（Wordにも下線が出ます） |
| AIに依頼 | 形式と補足を選ぶ | APIキーあり: AIが作問＋別解チェック／なし: 依頼文をコピー→結果を貼り付け |

作った問題は右側に「仕上がりの見た目」で並びます（通し番号も実際の番号で表示）。「編集」では
問題文・解答・解答枠・出典のほか、**選択肢（●で正解を選ぶ）・放送文・この問だけの配点（例: 9のみ2点）** を直せます。
「まとめて」メニューから **正解の位置をならす（1〜4を均等に）**・問題のコピー・一括削除ができます。
赤いバッジ（出典なし・解答なし・選択肢の重複 など）は配布前に必ず消してください。

#### 英単語テストは「単語リストから作成」

1. 英単語テストの大問で **「単語リストを貼り付けて作成」** を押す
2. Excel の単語表（番号・単語・意味・例文・例文の訳・英英定義）を **範囲選択してコピー → そのまま貼り付け**
   （列は自動で判別。違っていたら表の上の選択欄で直せます。Word の表を素材に入れてもOK）
3. 作る問題・番号の範囲・問題数を選ぶ → プレビューを確認 →「大問○に○問を入れる」

| 大問の形式 | 自動で作るもの |
|---|---|
| 放送された単語の意味 | 選択肢（意味4つ）＋放送文（模範解答の末尾に単語一覧として載る） |
| 英英定義 | 定義文の問題＋語群（10語など）。答えは語群の番号 |
| 英単語 → 意味／意味 → 英単語 | 4択。誤答は**同じリストの同じ品詞**から、意味が重なる語は除外 |
| 例文の空所（4択） | 例文の訳＋空所の英文。誤答の語形（過去形・三単現・複数形）を例文に合わせる |
| 例文の空所（綴り） | 頭文字ヒント付きの空所。答えは例文中の語形（例: created） |

- 正解の位置（1〜4）は均等になるよう自動配置。「作り直す」で選び直せます
- 貼り付けたリストは「共通」の素材として保存され、ほかの大問でもそのまま使えます
- 品詞の推定は完全ではありません。**配布前に選択肢を必ず確認**してください

#### 並び替えの別解警告の例

「What you need is to get enough sleep.」をそのまま並び替えにすると、
「To get enough sleep is what you need.」という別解が成立します。
ツールは **「to get が独立しています」と警告** します。
`is` と `to`、`to` と `get` の間の「＋」を押して **is to get** をひとまとまりにすると、警告が消えます。

### ③ チェック

#### 仮想の生徒に解かせる（AI）

AIの生徒（安いモデル）が **模範解答を見ずに全問を解き**、別のAI（上位モデル）が採点・検証します。

- **正答**: 想定どおりに解けたか
- **別解の疑い**: 生徒の答えが模範解答と違うのに、それも正解として成立する問題
- **要確認**: 問題文が分かりにくい・本文と矛盾する・生徒が迷った点
- **聞いている要素の重複**: 同じ文・語句・文法事項・本文の同じ箇所を2回聞いている問題の組
- 生徒のレベル（平均的／苦手／得意）と、全体か大問1つだけかを選べます。項目を押すとその問題へ移動します


- **自動チェック**: 配点合計（個別配点を含む）・問数・番号・出典・空欄・答えの重複・選択肢の重複／正解の範囲・
  正解の偏り・空所と解答枠の数（1枠1語）を機械的に確認します。項目を押すとその問題へ移動します
- **別解チェック**: APIキーがあればAIが全問を検証。なければ「別解チェック依頼文」を
  コピーして Claude / Codex に貼り付けます
- **配布前の最終確認**: 全問を自分で解き直した、などのチェックリスト

### ④ 出力

- 「Wordファイルを作成」で **問題用紙・解答用紙・模範解答**（Word）と
  **出典一覧**・**試験データ（JSON）** を作ります
- 問題用紙: 表紙・見出し・通し番号・選択肢の表（英単語テストの「16. haven ｜ 1. 植民地 ｜ 2. 議会 …」の形）・語群
- 解答用紙: 記入欄の表、1行に複数問を詰めた解答欄（記号は1行5問、記述は3問など）、使わない枠はグレー
- 模範解答: 解答・採点基準・放送文
- 画面でプレビューして、そのまま印刷することもできます。最終調整は Word で行ってください

## 3. 便利な機能

- **テンプレート**: 試験の型を保存・編集・複製（上の「テンプレート」参照）
- **カテゴリー**: 試験を自分で分類（ホームのチップ →「編集」）
- **複製**: 試験カードの複製ボタン → 前回の試験を土台に作り直せます
- **取り込み・バックアップ**（ホーム右上）
  - 試験データ（JSON）を取り込む: 出力した「データ（JSON）」や CLI の `exam_draft.json`
  - **バックアップを保存**: 全試験・素材・テンプレート・カテゴリーを1つのZIPに（PCの入れ替え時など）
  - **バックアップから復元**: 既存の試験は上書きせず、別の試験として追加されます
- **削除しても復元できる**: 削除した試験は保存先の `.trash` フォルダに移動します
- **Ctrl+S**: すぐに保存（通常は自動保存）
- **API使用量**: 左下（ホームは右上）の「API 今月 約○円」を押すと、今回・今月・合計の料金の目安と、
  いつ何に使ったか（作問・仮想の生徒・別解チェック）の明細が見られます（1ドル150円換算の目安。正確な請求額は各社の管理画面で）
- **AI機能（任意・有料）**: 左下の「API抜きモード」を押し、**Claude か ChatGPT** を選んでAPIキーを入れます
  （ツールを閉じると消えます。ファイルには保存されません）。
  ChatGPT は追加インストール不要。Claude は事前に `python -m pip install anthropic` が必要です。
  ChatGPTの月額プラン（Plus等）とAPIは別契約で、APIキーは platform.openai.com で発行します

## 4. 注意点

- 試験データは **使う人のPCの「ドキュメント」→「ExamStudio」フォルダ** に保存されます。
  ツールを他の先生に渡しても、データはその先生のPCに保存され、あなたのデータは渡りません。
  ツール本体を共有ドライブに置いて起動しても、データは各自のPCに保存されます
  （場所は「使い方」ボタンに表示されます。変えたい場合は `python -m exam_app.ui --workspace 保存先`）
- 試験の実物・模範解答を含むので、**生徒が閲覧できる場所に移さないでください**（バックアップZIPも同じです）
- ツールは **このPCのブラウザからしか開けません**（校内の他のPCからは見えない設定です）
- 生成物はドラフトです。**配布前に必ず教員が全問を解き直してください**
- 本文は一語も書き換えない設計ですが、貼り付けた本文自体の誤りはチェックできません

## 5. 困ったとき

| 症状 | 対処 |
|---|---|
| 起動しない・すぐ閉じる | Python が入っているか確認。コマンドで `python --version` |
| 「ポートが使用中」 | すでに起動していないか確認。`python -m exam_app.ui --port 9000` で別番号 |
| 画面に「サーバーに接続できません」 | 黒い画面を閉じていないか確認し、起動し直す |
| Wordファイルが読めない | .doc（古い形式）は .docx で保存し直す。PDFは本文を貼り付け |

## 開発者向け

- 構成: `exam_app/ui/server.py`（標準ライブラリのみのHTTPサーバー）＋ `exam_app/ui/static/`（依存ライブラリなし）
  - `layout.js`（番号・配点・解答用紙の詰め方）は `exam_app/layout.py` と同じ規則。変えるときは両方を直す
  - `app.js`（画面）・`templates.js`（テンプレート・カテゴリー・バックアップ）・`wordlist.js`（単語リストからの作問）
  - 設定は保存先の `settings.json`（カテゴリー）と `templates.json`（自作テンプレート）
- チェック・Word出力は CLI と共通（`exam_app/checks.py`・`exam_app/build_docx.py`）
- テスト: `python -m exam_app.tests.test_ui_server` / `python -m exam_app.tests.test_offline`
- 作問ルールの根拠: `skills/README.md`
