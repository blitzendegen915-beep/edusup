# 004 定期考査スタジオ（画面版の定期考査作成ツール）

状態: 完了 (2026-09)

## 目的
CLI中心だった exam_app を、教員が直観的に操作できる画面（ローカルWebアプリ）に作り直す。

## 成果物
- `exam_app/ui/` — 標準ライブラリのみのHTTPサーバー＋依存ライブラリなしの画面（オフライン対応）
- 5ステップ: 教材 → 試験構成 → 作問 → チェック → 出力
- クイック作問: 教材の文をクリック→形式を選ぶ→語をクリックで問題・解答・解答枠を自動生成
  （空所補充・並び替え・4択・語形変化・下線部・和訳、AI依頼はAPIあり/なし両対応）
- 並び替えの別解警告（to不定詞・副詞・重複語）、空所補充の頭文字ヒント
- チェック強化: 空欄検出、空所と解答枠の数の不一致（1枠1語）
- Word出力を解答枠の数どおりの枠・下線対応に改修（CLIと共通）
- 起動ファイル `start_exam_studio.bat` / `.command`、使い方 `docs/exam_studio.md`
- テスト: `exam_app/tests/test_ui_server.py`（APIテスト）＋ブラウザでの通し操作確認（18工程）
